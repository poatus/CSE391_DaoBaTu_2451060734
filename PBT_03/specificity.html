Specificity Battle - Bài B3

🎯 Mục tiêu

Viết 10 CSS rules khác nhau cùng target phần tử dưới đây, mỗi rule đặt color khác nhau.

Sắp xếp từ THẤP đến CAO theo specificity.

Phần tử demo:

Hello World

📊 Danh sách 10 Rules (Từ thấp đến cao)

# CSS Rule Specificity Giá trị Màu
1 p { color: black; } (0, 0, 0, 1) 1 Black
2 .text { color: blue; } (0, 0, 1, 0) 10 Blue
3 .highlight { color: green; } (0, 0, 1, 0) 10 Green
4 p.text { color: purple; } (0, 0, 1, 1) 11 Purple
5 p.highlight { color: orange; } (0, 0, 1, 1) 11 Orange
6 .text.highlight { color: brown; } (0, 0, 2, 0) 20 Brown
7 p.text.highlight { color: navy; } (0, 0, 2, 1) 21 Navy
8 #demo { color: red; } (0, 1, 0, 0) 100 Red
9 #demo.text { color: crimson; } (0, 1, 1, 0) 110 Crimson
10 p#demo.text.highlight { color: gold; } (0, 1, 2, 1) 121 Gold ⭐

🏆 Kết quả

Element cuối cùng hiển thị màu: GOLD

Giải thích:

  • Rule 10 có specificity cao nhất: p#demo.text.highlight = (0, 1, 2, 1) = 121
  • Bao gồm: 1 ID selector (#demo) + 2 class selectors (.text, .highlight) + 1 element selector (p)
  • ID selector có trọng số rất cao (100), vượt trội so với class (10) và element (1)
  • Khi specificity bằng nhau (như rule 2 và 3), rule khai báo SAU sẽ thắng

🧪 Thử nghiệm: Thay đổi thứ tự rules

Câu hỏi: Nếu thay đổi thứ tự các rules trong CSS file, kết quả có đổi không?

Trả lời: KHÔNG

Giải thích:

  • Specificity luôn được ưu tiên TRƯỚC thứ tự khai báo
  • Chỉ khi 2 rules có specificity BẰNG NHAU, thì rule khai báo sau mới thắng
  • Trong trường hợp này, rule 10 có specificity cao nhất (121), nên dù đặt ở đâu cũng thắng
  • Ví dụ: Rule 2 (.text) và Rule 3 (.highlight) có cùng specificity (10), nên rule 3 thắng vì khai báo sau

⚠️ Lưu ý quan trọng

Thứ tự ưu tiên CSS:

  1. !important - Cao nhất (tránh dùng nếu không cần thiết)
  2. Inline style - (1, 0, 0, 0) = 1000
  3. ID selector - (0, 1, 0, 0) = 100
  4. Class/Attribute/Pseudo-class - (0, 0, 1, 0) = 10
  5. Element/Pseudo-element - (0, 0, 0, 1) = 1
  6. Universal selector (*) - (0, 0, 0, 0) = 0

Công thức tính Specificity:

(inline, id, class, element)

  • Inline style: 1000 điểm
  • Mỗi ID: 100 điểm
  • Mỗi class/attribute/pseudo-class: 10 điểm
  • Mỗi element/pseudo-element: 1 điểm
