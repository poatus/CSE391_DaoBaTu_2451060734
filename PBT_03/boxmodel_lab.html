Phần 1: Content-box vs Border-box

Cả 2 hộp đều có: width: 300px; padding: 20px; border: 5px solid;

Hộp 1: content-box (mặc định)

Content-box

Width = 300px

Padding = 20px

Border = 5px

Tổng = 350px

Chiều rộng thực tế: 300 + 40 + 10 = 350px

Hộp 2: border-box

Border-box

Width = 300px

Padding = 20px

Border = 5px

Tổng = 300px

Chiều rộng thực tế: 300px (content = 250px)

📝 Giải thích:

  • Content-box: width chỉ tính content. Padding và border được CỘNG THÊM.
  • Border-box: width bao gồm content + padding + border. Browser tự tính content.
  • Kết luận: border-box giúp tính toán layout dễ dàng hơn!

Phần 2: Layout 3 cột (1000px)

Trường hợp 1: KHÔNG dùng border-box (BỊ VỠ)

⚠️ Tổng chiều rộng: 250 + 500 + 250 = 1000px (theo khai báo)
Nhưng thực tế: (250+30) + (500+40) + (250+30) = 1100px > 1000px → Layout bị vỡ!

Sidebar (250px)

padding: 15px

Thực tế: 280px

Content (500px)

padding: 20px

Thực tế: 540px

Ads (250px)

padding: 15px

Thực tế: 280px

❌ Cột Ads bị đẩy xuống dòng mới vì tổng > 1000px

Trường hợp 2: Dùng border-box (HOẠT ĐỘNG)

✅ Với border-box, width bao gồm padding → Tổng đúng 1000px

Sidebar (250px)

padding: 15px

Thực tế: 250px ✓

Content (500px)

padding: 20px

Thực tế: 500px ✓

Ads (250px)

padding: 15px

Thực tế: 250px ✓

✅ Tất cả 3 cột nằm cạnh nhau hoàn hảo!

📊 So sánh:

Cột Width khai báo Padding Content-box (thực tế) Border-box (thực tế)
Sidebar 250px 15px × 2 280px 250px ✓
Content 500px 20px × 2 540px 500px ✓
Ads 250px 15px × 2 280px 250px ✓
TỔNG 1000px - 1100px ❌ 1000px ✅

💡 Best Practice: Luôn thêm * { box-sizing: border-box; } vào đầu mọi dự án CSS!
